# v1.1.7 安装与发布记录

2026-11-09，当前 UniDepth 多后端版本。源码按本次用户要求更新到 `main`，安装包及 SHA256 对应 [v1.1.7 Release](https://github.com/QinChen1998/depth-camera-and-tactile-sensor/releases/tag/v1.1.7)。历史 v1.1.6 保留原文件。

## 交付内容

「设置 → 推理设备」在启动时实际加载模型、预热和试推理，只显示成功的选项。首次优先可用的 TensorRT-RTX；没有可用 TensorRT 时，在通过测试的原精度路径中按短时模型速度选择。用户可以改选并保存偏好；混合 INT8 单独选择。失败时回退到已验证的 CPU 路径，完整性失败不回退明文。详细范围和性能解释见 [推理设备选择](MULTI_BACKEND_INFERENCE.md)。

安装器包含 TensorRT-RTX、DirectML、OpenVINO CPU／Intel GPU、通用 ORT CPU 的原生库，以及 Qt、VC++、视频、ADB、原生采集支持和许可材料。不需要用户安装 Python、Conda、PyTorch、CUDA Toolkit 或 OpenVINO SDK。显卡驱动仍由系统／硬件厂商提供；驱动或算子不满足要求时不显示对应 GPU 选项。

仅使用当前 RGB672／640×480 UniDepth。原模型没有覆盖或修改；decoder 混合 INT8 是独立模型。两个模型分别通过 AES-256-GCM 和原生 DLL 内存加载保护，交付目录不含明文 ONNX／IR、开发密钥头文件或 Python。完整契约见 [模型保护](MODEL_PROTECTION.md)。

同时包含当前 F6 标定、48×32 原生 ToF 普通／高精度两档、USB 自动接入修复和旧 LiteSR／Tiny 入口退役。这两档原生 ToF 直接输出传感器测量，不使用神经网络。当前模式与标定见 [对应说明](DEFAULT_CALIBRATION_NATIVE_TOF.md)。

## 验证记录与边界

本轮证据根目录为 `x64/validation/multibackend_20261109/`，最终发布文件保存在其 `installer-public-1.1.7-r2/delivery/`。测试原件含本机路径及部分设备身份，仅本地保留。

- 开发版 Release／Debug 八组统一离线专项各 1,390 个断言通过；公开源码补齐本地开发依赖后，64 项 Python 回归通过。
- 同后端原图／保护加载对照：五条路径各 22 个用例，13 组输出逐字节一致。原模型 TensorRT 基线对照、密文破坏／缺失／身份错误拒绝均通过。原件在 `protected-parity/`、`protected-rejections-02/` 和 `rtx-parity/`；这些对照先于新增实机测试入口、设备脱敏与符号引用调整的最终重构建，模型执行与保护加载实现未改变。
- 最终发布载荷五条路径的实际模型检测、加密加载、完整深度输出及设置页通过，记录在 `native-public-final/`。两个新密文各自回验的明文字节与只读输入完全一致。
- 最终发布程序连接真实 RV1103，每条路径两轮各 30 秒；实际深度、显示、停止、重启、100 ms 捕获配对和长期参数保持均通过，停采后晚到结果为零。此轮只验证主机 H，原件在 `live-public-final/`。

清洁环境复验发现控制程序的旧自检依赖开发设备预登记公钥。现已改为在自检作用域使用独立测试公钥，仍验证错误公钥、空公钥及算法降级拒绝；该测试身份不会进入默认信任、设备档案或网络会话。无预登记密钥的公开控制程序通过 61 项检查，本地保留旧身份的 Release／Debug 各通过 63 项。最终重新封装只改变控制程序和两份清单；其中板端导入清单仅 JSON 序列化不同，解析内容相同，主程序、推理程序、所有模型和依赖均逐字节未变，见 `installer-public-1.1.7-r2/payload-comparison.json`。

更新控制程序后又对真实设备执行两轮 H 启停复核，约 30.01／30.00 FPS，正常停采且长期参数不变，记录在 `live-public-r2-control/`。

最终安装包在关闭网络、关闭 vGPU、8 GiB 内存的新 Windows Sandbox 中完整通过：安装、实际 CPU 模型推理、三项可用 CPU 选项检测及默认选择、完整深度输出、八组共 1,389 个桌面断言、61 项原生控制程序自检、普通中文窗口启动和关闭、重装及卸载。卸载移除主程序、推理程序、模型、运行库、快捷方式与卸载登记，并保留用户配置。原件在 `installer-public-1.1.7-r2/sandbox-results-cpu-clean-final/`；前一份自检失败记录保留，没有作为通过结果。最终证据汇总为 `verification-public-final.json`。
